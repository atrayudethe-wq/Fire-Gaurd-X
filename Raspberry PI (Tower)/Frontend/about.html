FireGuardX

Autonomous Fire Detection & Extinguishing System

Created & Developed by:
Ved Patil & Atrayu Dethe

Project Overview

FireGuardX is an advanced, autonomous IoT robotics platform designed to navigate hazardous environments, detect fire and smoke anomalies, and take immediate corrective action. Built for rapid emergency response, the system combines edge-AI computer vision with robust microcontroller networking.


System Architecture

  • The Vision Brain (Raspberry Pi): Runs a Flask server and utilizes Ultralytics YOLOv8 for real-time, AI-driven optical detection of fires and smoke.
  • The Master Gateway (ESP32): Acts as the central nervous system, handling local telemetry via an HMC5883L magnetometer, managing Wi-Fi connectivity to the Pi, and securely logging data offline using LittleFS.
  • The Slave Executor (ESP32): Communicates with the Master via low-latency ESP-NOW protocol. It executes physical motor commands, sweeps a 270-degree servo, and continuously monitors analog environmental sensors (MQ Gas, IR Flame, Ultrasonic, and DHT11).

Core Features

  • Real-Time Telemetry: Live sensor data, compass headings, and AI video feeds pushed to a central web dashboard.
  • Autonomous & Manual Control: Automated hazard suppression with failsafe protocols, alongside manual web-based overrides.
  • Resilient Communication: Self-healing network loops with offline data caching and bulk-upload recovery.
